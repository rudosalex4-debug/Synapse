# Контракт API

- [OpenAPI 0.12.0](openapi.v0.12.json) - актуальное описание методов, моделей, параметров и авторизации. [openapi.json](../openapi.json) в корне - копия для передачи проверяющим.
- [Получение доступа и примеры API](../docs/API.md) - учебные роли для локального запуска, реальные сессии MAX, ревизии и идемпотентность.
- `DATA-API.yaml` - отдельное требуемое описание сценариев для платформы оценки; в эту поставку пока не включено. OpenAPI не заменяет этот материал.

Версия API: **0.12.0**, OpenAPI: **3.1**. Фактический HTTPS-origin передаётся с материалами сдачи; локальное значение `servers.url` заменяется в выбранном HTTP-клиенте на адрес проверяемого экземпляра. После локального запуска для жюри это `http://localhost:18080`.

Доступ к обычным защищённым операциям осуществляется по Bearer-сессии участника. Токен бота, webhook secret, пользовательские токены и личные MAX ID не входят в контракт и не публикуются в Git. Общий доступ MAX сохраняет проверку личности, ограничения на чужие данные и отдельные права модератора.

Наличие этих файлов описывает интерфейс поставки; оно не подтверждает прохождение проверок или доступность внешнего сервера.
